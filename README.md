
# Netflix Movies and TV Shows Data Analysis

## Project Overview
This project explores the Netflix Movies and TV Shows dataset
using Python. It focuses on Exploratory Data Analysis (EDA)
and Data Visualization.

## Objectives
- Analyze Movies and TV Shows distribution.
- Identify countries contributing the most titles.
- Explore popular content genres.
- Examine release year trends.
- Understand content ratings distribution.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Tasks Completed
1. Exploratory Data Analysis
2. Data Visualization

## Data Cleaning
- Inspected missing values.
- Handled missing text values using Unknown.
- Handled missing release years using median imputation.
- Checked and removed duplicate records.

## Visualizations
1. Movies vs TV Shows
2. Top 10 Countries
3. Top 10 Genres
4. Content Release Trends
5. Content Ratings Distribution
